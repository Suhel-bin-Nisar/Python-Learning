# 🐍 Chapter 06 — Conditional Expression

This chapter covers conditional expressions in Python, including `if`, `else`, `elif`, relational operators, and logical operators.

## 📚 Topics Covered

### Conditional Statements
- `if` statement
- `if-else` statement
- `if-elif-else` ladder
- Conditional decision making

### Relational Operators
- `==` — equals
- `>=` — greater than or equal to
- `<=` — lesser than or equal to

### Logical Operators
- `and` — true if both operands are true
- `or` — true if at least one operand is true
- `not` — inverts `True` to `False` and `False` to `True`

### Elif Clause
- Using multiple `elif` statements
- How the `if / elif / else` ladder works
- `else` executes when all previous conditions fail

## 📝 Practice Set

### 1. Greatest of Four Numbers
Find the greatest of four numbers entered by the user.

### 2. Student Pass or Fail
Check whether a student has passed or failed based on 40% total marks and at least 33% in each of 3 subjects.

### 3. Spam Comment Detector
Detect spam comments containing:
- `Make a lot of money`
- `buy now`
- `subscribe this`
- `click this`

### 4. Username Length
Check whether a username contains less than 10 characters.

### 5. Name in List
Check whether a given name is present in a list.

### 6. Student Grade
Calculate the grade according to the given marks scheme:
- 90–100 → Ex
- 80–90 → A
- 70–80 → B
- 60–70 → C
- 50–60 → D
- Below 50 → F

### 7. Harry in Post
Check whether a given post is talking about `Harry` or not.
